# SentinelGuard Electron

Desktop application wrapper for SentinelGuard using Electron.

## Features
- Native desktop integration
- System tray icon
- Native notifications
- Auto-update capability
- Windows/macOS/Linux support

## Setup

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Project Structure

- `main.js` - Electron main process
- `preload.js` - IPC bridge
- `renderer/` - React frontend code
